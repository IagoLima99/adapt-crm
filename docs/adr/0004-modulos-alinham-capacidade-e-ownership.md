# Modules alinham capacidade e ownership

Cada Module representa simultaneamente uma capacidade coesa do produto e o limite de ownership de suas regras e dados. Modules essenciais recebem Module Entitlement de sistema não revogável e Module Activation durante o provisionamento de todo Tenant; Modules opcionais dependem de concessão e escolha explícitas. Infraestrutura e bibliotecas compartilhadas não são Modules. Essa correspondência evita limites técnicos desconectados do produto, mas exige contratos explícitos para colaboração entre Modules.
