# Acesso a Modules por Entitlement, Activation e RBAC

O acesso a uma capacidade exige Module Entitlement do Tenant, Module Activation e autorização RBAC do User em sua Membership. No caso de Modules essenciais, Entitlement e Activation são concessões de sistema criadas no provisionamento e não podem ser revogadas pelo Tenant. Feature flags servem apenas para rollout ou kill switch e podem restringir, mas nunca conceder acesso.
