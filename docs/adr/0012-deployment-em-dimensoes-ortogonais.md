# Deployment em dimensões ortogonais

Deployment será descrito por dimensões combináveis: Isolation Mode (`shared` ou `dedicated`), Operations Mode (`managed` ou `self-hosted`) e Runtime (`local`, `VPS/Compose` ou `Kubernetes`). Isso evita misturar modalidade comercial, responsabilidade operacional e tecnologia de execução. Kubernetes permanece uma escolha baseada em métricas, não uma categoria de cliente.
