# Templates não concedem Entitlements

Um Template pode solicitar Module Activations, mas nunca concede Module Entitlements. Antes da aplicação, todos os Entitlements necessários são validados; ausência de qualquer direito interrompe a operação inteira, sem aplicação parcial ou silenciosa. A regra preserva a separação entre configuração e disponibilidade contratual.
