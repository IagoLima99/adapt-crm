# Desativação de Module preserva dados

Desativar um Module bloqueia novos comandos e execuções, mas preserva seus dados. Workflows em andamento devem alcançar estado seguro antes de a desativação concluir, e uma reativação restaura o acesso. Exclusão obedece a um processo separado de retenção e nunca ocorre implicitamente como efeito da desativação.
