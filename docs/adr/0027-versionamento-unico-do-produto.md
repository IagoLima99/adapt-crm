# Versionamento único do produto

O artefato AdaptCRM possui uma única versão SemVer. Modules têm identificador estável e versão de contrato ou configuração para compatibilidade e migrations, mas não releases implantáveis independentes. Templates declaram compatibilidade com versões do produto e contratos de Module, evitando falsa independência dentro do monólito.
