# Administração cross-tenant separada

Platform Operator usa concessão platform-scoped separada de Memberships, protegida por MFA. Ações cross-tenant passam por endpoints e caminhos de dados administrativos próprios, exigem motivo ou ticket, privilégio temporário e auditoria. Impersonação não faz parte do produto inicial; emergências seguem procedimento break-glass explícito.
