# Rastreador de issues

O Jira é a fonte oficial para planejamento e acompanhamento deste repositório.

- Instância: `https://codemacro.atlassian.net`
- Projeto: Equipe Lua
- Chave do projeto: `EL`
- Integração preferencial: MCP Atlassian Rovo

Use pesquisa natural do Rovo para descoberta e JQL quando for necessário consultar campos, estados ou conjuntos de issues com precisão.

Antes de alterar uma issue, leia seu conteúdo atual e preserve a hierarquia Epic → História/Tarefa → Subtask, suas dependências, critérios de aceite e não-objetivos.

Novos itens de trabalho devem ser registrados no projeto `EL`. Quando aplicável, referencie a chave da issue em branches, commits e pull requests.

GitHub Issues e arquivos locais em `.scratch/` não são rastreadores oficiais deste projeto.
