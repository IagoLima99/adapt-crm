# Labels de triagem

As skills usam cinco papéis canônicos de triagem. Esta tabela relaciona cada papel ao label utilizado no Jira.

| Papel canônico | Label no Jira | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Requer avaliação do mantenedor |
| `needs-info` | `needs-info` | Aguardando mais informações |
| `ready-for-agent` | `ready-for-agent` | Especificado e pronto para execução por agente |
| `ready-for-human` | `ready-for-human` | Requer implementação ou decisão humana |
| `wontfix` | `wontfix` | Não será executado |

Quando uma skill mencionar um papel de triagem, use o label correspondente desta tabela.
