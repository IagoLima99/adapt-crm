# Pacotes compartilhados

Somente bibliotecas técnicas reutilizáveis podem ser publicadas neste diretório:

- `python/` para pacotes Python;
- `typescript/` para pacotes TypeScript.

Aplicações não importam umas das outras. Regras de negócio, ownership de dados e capacidades de Module permanecem fora de `packages/`. Consulte [`docs/development/monorepo.md`](../docs/development/monorepo.md).
